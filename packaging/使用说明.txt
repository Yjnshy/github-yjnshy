帅羊羊DLY —— 视频下载 & 直播录制
=====================================

一、怎么启动
------------
双击 DLY.exe 即可打开窗口，不需要安装 Python。

如果 Windows 弹出「已保护你的电脑」：
    点「更多信息」→「仍要运行」。
    原因是没有购买代码签名证书，所有未签名的 exe 都会这样提示，不是病毒。


二、第一次使用汽水音乐之前（完整版音频）
----------------------------------
汽水音乐页签可以粘贴分享链接导入音频和封面。这里分两种：

1. 合成片段（约 30-60 秒）：免登录，直接粘贴链接就能采集。

2. 完整音频（整首）：需要两个条件，缺一不可——
   a. 本机安装「汽水音乐」电脑版（Windows 客户端）。DLY 要借它内置的
      音频签名组件才能拿到完整音频；不装的话只能采集合成片段。
      装一次即可，不用一直开着。
   b. 在 DLY 汽水页签点「扫码登录（抖音 APP）」登录你自己的账号，
      或用「手动粘贴 Cookie 登录」。登录态只存本机。
   两个条件都满足后，粘贴链接采集到的就是完整音频。
   页面上方会显示当前状态（缺客户端 / 待登录 / 完整版就绪）。

   注意：登录 Cookie 会过期，过段时间若又只采到片段，重新登录一次即可。
   请用自己的账号，且仅用于个人离线备份，不要分发下载的内容。

三、第一次使用抖音 / B 站 / 小红书之前
--------------------------------------
最简单的办法：打开「设置 → 登录账号」，点对应网站的「登录」，
程序会弹出一个小窗口，用手机扫码或输入账号登录即可。登录一次就记住了，
以后不用再操作；换电脑或点「退出」会清掉。

只有在下载高清、会员或完整作品时才需要登录，普通链接不登录也能下。

如果登录窗口用不了，还有两个备选（「设置 → 高级：手动提供登录信息」）：
A. 在浏览器装 Cookie 导出扩展（如 Cookie-Editor），登录目标网站后导出
   Netscape 格式的 cookies.txt，点「选择文件」导入并保存；
B. 直接从浏览器开发者工具里复制整段 Cookie，粘贴到「手动输入 Cookie」
   输入框并保存（格式：name=value; name2=value2; ...）。
说明：新版 Edge / Chrome 启用了应用绑定加密（App-Bound Encryption），
Windows 不允许第三方程序直接读取浏览器的 Cookie，所以「自动读浏览器」
这条路对 Edge 基本失效——这也是推荐用上面「登录账号」的原因。

以上内容都只保存在本机，不上传。

四、各个页签分别做什么
----------------------
1. 下载视频
   粘贴视频链接或整段分享文案 → 选画质和帧率 → 开始下载。
   「帧率」只能降低，不能凭空变高（30fps 转 60fps 只是复制帧）。

2. 录制直播
   填直播间地址 → 选帧率（默认「原帧率」不转码、最省 CPU）→ 开始录制。
   「录制时长」可填秒 / 分钟 / 小时，录满会自动停止并保存；填 0 表示不限时，
   需要自己点「停止录制」。默认不勾「到点后自动续录下一段」= 只录这一段就结束；
   勾选后到点会重新检查直播间，仍在开播就接着录下一个文件
   （文件名带 _part02、_part03…，状态栏会显示当前第几段）。
   注意：勾选状态在点「开始录制」时就固定了，录制开始后再改不影响本次任务。
   录制格式默认 ts，断电或强杀进程也不会把文件弄坏。
   文件按主播归类：直播录制/<平台>-<主播昵称>-<主播号>/<录制时间>_<直播标题>.ts，
   同一个主播的每场直播都在同一个文件夹里。
   录完（或下载完）点界面上的「打开文件位置」，会直接在资源管理器里选中该文件。

3. 无人值守
   一行一个直播间地址 → 开始值守。
   开播自动录、下播自动停、断线自动重连，窗口最小化不影响运行。

4. 音乐
   导入汽水音乐分享链接（详见第二节），或管理已下载到歌单的音频；
   支持普通列表和三维封面隧道两种视图，点封面即可播放。

5. 我的文件 / 历史
   「我的文件」按平台归类已下载的视频和音频；「历史」是最近的下载/录制记录。

6. 设置
   改默认保存目录、画质与帧率、录制默认值、Cookie 来源、值守房间列表、
   提示音与日志级别，点「保存设置」后写入 config.yaml，重启仍生效。
   顶部的像素开关用来切换日间 / 夜间主题：点按、左右拖动，或聚焦后按
   空格 / 回车都可以；侧栏底部还有一个缩小版，随时能切。
   第一次打开跟随系统深浅色，手动切换后会记住。


五、文件存在哪
--------------
默认下载目录：本机 %LOCALAPPDATA%\DLY\downloads
日志文件：    %LOCALAPPDATA%\DLY\logs\dly.log
窗口里点「选择目录」，自己挑一个保存位置；不改就用默认目录。

想出问题好排查，就把上面的日志文件发出来。


六、想改默认设置
----------------
常用设置直接在窗口「设置」页里改并保存即可，不用手工编辑文件。

也可以把 config.example.yaml 复制成 config.yaml，放在 DLY.exe 同一个目录，
改完重启程序生效。常用项：output_dir（保存目录）、quality（画质）、
record.fps（录制帧率）、record.segment_minutes（分段分钟数）、
ui.theme（system / light / dark）、ui.sound、ui.log_level。
注意：从设置页保存会整理 config.yaml 的格式（注释会被去掉），
但所有配置项的值都会原样保留。
